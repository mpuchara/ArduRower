ESP32-2432S028 · 2,8″ · BLE FTMS

ArduRower CYD

Wgraj firmware do żółtej płytki ESP32 z wyświetlaczem 320 × 240 i wykresami mocy oraz prędkości. Bez Arduino IDE — wystarczy Chrome lub Edge na komputerze i kabel micro-USB do transmisji danych.

Ważne przed wgraniem
Instalacja zastąpi program obecnie działający na płytce (np. UBox). Nie wgrywaj, jeśli nie możesz później przywrócić starego firmware. Nie odłączaj kabla podczas zapisu. To wciąż eksperymentalny port — nie był jeszcze zweryfikowany na fizycznym CYD z zegarkiem.

Wyświetlacz potwierdzony: ST7789 / GPIO21

Wykryty i sprawdzony na Twojej płytce profil: ST7789 z podświetleniem GPIO21. Inne warianty zostały usunięte z instalatora i kompilacji.

Nowa wersja eliminuje miganie ekranu: nie czyści go cyklicznie. Statyczne obszary pozostają na miejscu, a zmienione liczby i wykresy są aktualizowane za pomocą niewielkiego bufora w RAM.

2. Podłącz płytkę i zainstaluj

  1. Podłącz micro-USB do komputera, na którym działa Chrome lub Edge. Wybierz działający port COM (np. COM4, ale numer może być inny).
  2. Kliknij Połącz i zainstaluj. Firmware jest przeznaczony wyłącznie dla ST7789/GPIO21.
  3. Potwierdź port szeregowy, wybierz instalację i postępuj zgodnie z komunikatami. Jeżeli pojawi się pytanie o kasowanie pamięci, pamiętaj, że usunie ono poprzednią konfigurację.
  4. Po wgraniu płytka powinna uruchomić dashboard ArduRower. Następnie sprawdź odbiór przez dotychczasowe pole Connect IQ w Garminie.

Wybrano: ST7789 / podświetlenie GPIO21

Przeglądarka nie obsługuje Web Serial. Użyj Chrome lub Edge na komputerze. Instalator wymaga strony HTTPS.
Instalator czeka na publikację firmware. W ustawieniach repozytorium GitHub przełącz Settings → Pages → Build and deployment → Source z „Deploy from a branch” na GitHub Actions. Następnie sprawdź, czy akcja „ArduRower CYD — Pages installer” zakończyła się sukcesem.

3. Podłączenie wioślarza i zegarka

Kontaktron: GPIO22 + GND (nie GPIO2 — zajmuje go TFT). Sprawdź fizycznie pinout złącza P3 swojej rewizji płytki. Garmin: pozostaje dotychczasowa nazwa WR S4BL3, usługa FTMS i format danych BLE, kompatybilny z dotychczasowym polem Connect IQ.

Moc i prędkość na wykresach są estymowane. Odczyty nie stanowią bezpośredniego pomiaru watów ani kalibracji Concept2. Poprawkę odświeżania należy potwierdzić na fizycznej płytce.
